# MODOTEX — демоверсия сайта студии оформления окон

Готовый статический сайт для публикации на Vercel. 1 страница, оригинальные SVG-иллюстрации, интерактивный подбор оформления окна и подготовка заявки в сообщения ВКонтакте.

## Как открыть и опубликовать

**Локально:** откройте `index.html` в Chrome или другом современном браузере. Интернет не требуется для отображения иллюстраций, стилей и работы конструктора.

**Vercel:** распакуйте архив, загрузите исходные файлы в новый репозиторий GitHub; импортируйте репозиторий в Vercel, выберите `Framework Preset: Other`, корневую папку проекта и выполните Deploy. Команды сборки не нужны. Можно также использовать Vercel CLI `vercel --prod` из корня проекта.

**Если нужен локальный сервер**: `python3 -m http.server 8080` и перейти на `http://localhost:8080`.

## Функциональность

- Адаптивный сайт (320–1440+ px), мобильное меню.
- Два направления: классические шторы/домашний текстиль и солнцезащитные системы.
- Фильтры галереи дизайн-концепций, модальное окно просмотра.
- Интерактивный SVG-конфигуратор: портьеры/рулонные/плиссе/жалюзи, комната, цвет, плотность или доля закрытия, размеры, крепление, комментарий.
- Локальный выбор до трёх изображений (JPEG/PNG/WebP/GIF, до 8 МБ на файл) с предпросмотром и удалением. **Изображения не передаются на сервер и не прикрепляются автоматически к VK.**
- Копирование подготовленной заявки, прямой переход в VK-сообщения.
- FAQ, мобильная адаптация, семантическая разметка, состояние элементов, поддержка reduced motion.

## Важные ограничения

Сайт — **независимая коммерческая демоверсия**, а не официальный сайт компании.

- Визуальные иллюстрации выполнены специально для проекта, **не являются фотографиями реализованных объектов Modotex**.
- Не указаны непроверенные цены, акции, сроки изготовления, отзывы и рейтинг.
- В доступных справочниках фигурирует адрес пр. Серебрякова, 14, но актуальный адрес приёма клиентов не подтверждён. По этой причине адрес не указан в сайте.
- Возможность бесплатного выезда дизайнера заявлена в описании VK; условия нужно уточнить у компании.
- Заявка формируется на устройстве, а не отправляется автоматически. Пользователь копирует текст и вставляет его в чат VK.
- Перед публикацией в качестве официального сайта нужно получить согласие владельца и заменить демонстрационные описания на подтверждённые условия.
- Для запуска поисковой индексации после утверждения владельцем удалите `<meta name="robots" content="noindex,nofollow,noarchive">` и правило `X-Robots-Tag` в `vercel.json`.
